# Night Watch branding

Canonical product artwork for `@thenightwatch/*`, the API, playground, and console.

| File | Use |
|---|---|
| `night-watch-hero.jpg` | Master / full scene (source of truth) |

## Palette

| Token | Hex | Role |
|---|---|---|
| `--nw-void` | `#070b14` | Background / night |
| `--nw-ice` | `#d7e0ea` | Metallic silver text |
| `--nw-cyan` | `#3ad7ff` | Biometric / accent glow |
| `--nw-wall` | `#1a2740` | Secondary surface |

## Rules

- Prefer these files; do not re-export third-party Fingerprint / FingerprintJS marks.
- Keep the wolf + fingerprint lockup intact; do not separate the fingerprint from the wolf in primary logos.
- For tiny favicons (≤32px), use `night-watch-icon-32.png` (full lockup cropped square).
